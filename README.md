# 색봄 — 간단한 색 확인 앱

`dist/index.html` 하나로 동작하는 웹앱입니다. 별도 설치, 서버, API 키가 필요하지 않습니다.

## 실행

`dist/index.html`을 브라우저로 열어 주세요. 휴대폰에서는 웹 주소를 기본 브라우저로 열면 됩니다.

1. 글자 / 음성 / 둘 다 중 안내 방식을 저장합니다.
2. 사진 촬영 또는 사진 불러오기를 누릅니다. 휴대폰 촬영 버튼은 기기의 기본 카메라 선택 기능을 사용합니다. PC에서는 파일 선택 창이 열릴 수 있습니다.
3. 사진 가운데 색을 먼저 분석합니다. 궁금한 곳을 누르면 해당 위치 주변 11×11 픽셀의 평균 색을 알려줍니다.
4. 예시로 체험 버튼을 누르면 사진 없이도 동작을 확인할 수 있습니다.

## 구현

- HTML: 화면, 설정창, 사진 입력
- CSS: 휴대폰 대응, 큰 글자, 대비, 키보드 포커스
- JavaScript Canvas: 사진 분석, RGB→HSV 기반 한국어 색 이름
- SpeechSynthesis: 한국어 음성 안내 (기기와 브라우저의 한국어 음성 지원 필요)
- localStorage: 안내 설정 저장 (브라우저가 저장을 허용하는 경우)
- 흰색 기준 보정: 사용자가 지정한 흰 부분의 RGB 비율로 분석값만 보정. 사진 원본은 변경하지 않음

사진은 업로드하지 않고 브라우저 안에서 처리합니다. 검은 물체와 어두운 조명을 완벽히 구별할 수 없어 매우 어두운 지점에는 촬영 안내를 표시합니다. 주변 색이 많이 섞인 곳에도 다른 위치를 선택하도록 안내합니다. 색 이름은 간단한 규칙으로 추정하므로 조명, 그림자, 카메라 처리에 따라 실제 색과 다를 수 있습니다. 흰색 기준 보정은 사진에 실제 흰색 물체가 있을 때만 사용하세요.

선택한 사진 영역은 키보드 방향키로 옮기고 Enter로 확인할 수도 있습니다. 외부 라이브러리나 빌드 과정은 없습니다.
